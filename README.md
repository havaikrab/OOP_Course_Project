# OOP Course Project

## Описание:
OOP Course Project - это проект, созданный в рамках обучения языку программирования Python.  
Основной задачей проекта является получение, сохранение в Excel-файл и отбор в соответствии с выбранными критериями
вакансий, предоставляемых сайтом [HeadHunter.ru](https://hh.ru/).  

## Цель проекта:
Главной целью OOP Course Project является закрепление полученных ранее знаний и навыков работы в сфере
объектно ориентированного программирования языка Python.  
А также повторение материала предыдущих уроков, и применение всех полученных знаний на практике, то есть, для решения  
задач, приближенных к реальным.


## Установка:
1. Запустите IDE на локальном ПК.


2. Клонируйте OOP Course Project из удаленного репозитория.

    Для этого из текущей директории на вашем ПК можно ввести в терминале команду:  
git clone git@github.com:havaikrab/OOP_Course_Project.git


3. Установите зависимости.

    В проекте используется менеджер зависимостей Poetry, установите его, при необходимости.
    Для установки зависимостей введите в терминале команду: poetry install

## Запуск:
Вся коммуникация с приложением происходит при запуске файла main.py в корне проекта.
Подробнее об алгоритме работы программы будет рассказано ниже, после описания всех функций и классов,
обеспечивающих его работу  

## Комментарии к модулям:

### base_manager.py и base_request.py

Данные модули содержат описание соответствующих абстрактных классов.  
BaseManager - класс, отвечающий за работу с файлами. Обязывает наследующиеся классы описать методы записи
информации в файл, чтения данных из файла, очистки файла данных.  
BaseRequest - класс работы с внешними ресурсами, обязывает наследующиеся классы описать методы получения данных
из интернета.  

### head_hunter_research.py  

Данный модуль содержит описание класса HHResearch, наследующегося от BaseRequest.  
Экземпляром класса является некий шаблон, содержащий информацию, необходимую для отправки запроса
сайту [HeadHunter.ru](https://hh.ru/).
Все атрибуты экземпляров класса приватные:  
__url - неизменный атрибут - стока ссылки на API сайта [HeadHunter.ru](https://hh.ru/).  
__headers - неизменный атрибут - словарь с заголовком для отправки запроса.  
__params - атрибут параметров запроса - словарь, в котором значения ключей, опционально, определяются
при инициализации нового объекта класса. А именно:  
text - ключевое слово для поиска подходящих вакансий  
area - код страны, региона, или города в соответствии с классификацией сайта
per_page - количество вакансий, возвращаемых одним запросом, по умолчанию равно 100.  
__response - атрибут, которому присваивается список вакансий, полученных при обращении к сайту.  
__status_code - атрибут, значение которого равно значению атрибута status_code объекта response созданного
в результате обращения к внешнему ресурсу.

Приватный метод __check_connect - отвечает за проверку соединения с сайтом вакансий перед отправкой get-запроса.  
Публичный метод get_response - главный метод получения данных с сайта [HeadHunter.ru](https://hh.ru/).  
При вызове данного метода формируется список объектов класса Vacancy - основного материала для работы программы.  
Стоит отметить, что максимальное количество вакансий, возвращаемых методом get_response не может превышать
2000 экземпляров, это связано с ограничениями сайта.  

### vacancy.py  

В данном модуле описан класс Vacancy. Каждый экземпляр данного класса содержат информацию об
одной конкретной вакансии. Атрибутам объекта класса при создании присваиваются такие характеристики,
как название вакансии, идентификационный номер, зарплата и так далее. Все описания атрибутов можно прочитать
в документации метода \_\_init__.  
В классе также описаны методы сравнения вакансий по размеру заработной платы.  
Описан метод \_\_str__ для предоставления краткой информации об объекте класса.  
Описан метод to_dict, преобразующий объект класса в словарь с названиями ключей,
необходимых для пересоздания объекта.
Описан статический метод reform_original - преобразующий словарь, получаемый при обращении к сайту HeadHunter в словарь для
создания нового объекта класса.  
Также описаны геттеры атрибутов класса.
Описан сеттер атрибута __salary, в частности, для удобства тестирования программы.

### salary.py  

В данном модуле описан класс Salary. Экземпляры данного класса, представляют описание зарплаты и присваиваются
атрибуту __salary класса Vacancy в случае, если в вакансии корректно указана зарплата.  
Класс Salary имеет, аналогично классу Vacancy, описание методов сравнения объектов класса,
предоставления краткой информации о зарплате, а также, методов преобразования в словарь и формирования словаря,
необходимого для создания нового объекта класса.  
Также на уровне класса указаны атрибуты:  
required_currency - строка названия валюты, которая может быть опционально задана.  
currency_rates - объект класса ApilayerRates, предоставляющий информацию о курсах любых других валют, относительно
required_currency.
Для установки значений вышеуказанных атрибутов используется класс-метод set_currency_rates.  
Наличие required_currency и currency_rates позволяет расширить возможности сравнения размеров зарплат в разных валютах
путем приведения их к одной, указанной в required_currency.  
Также в классе описан метод converted_salary, позволяющий оценить размер зарплаты в удобной для пользователя валюте.  

### currency_rate_revision  

В данном модуле описан класс ApilayerRates. Как уже было сказано, данный класс отвечает за предоставление курсов валют,
относительно той, что указана при создании объекта класса. При создании объекта класса, также опционально, может быть
указано название файла, который будет хранить актуальную информацию о курсах валют.  
В классе описаны вспомогательные приватные методы, чтения, обновления, удаления информации о курсах валют.  
Описан метод конвертации сумм из произвольной валюты в валюту объекта класса.  
ApilayerRates наследуется от BaseRequest, и имеет обязательный метод get_response. Данный метод, при вызове
проверяет наличие локально-сохраненной информации о курсах валют. Если таковой информации нет, или она устарела,
происходит запрос к API сайта [apilayer.com](https://hh.ru/). Полученные данные записываются в файл, указанный при
создании объекта класса, для возможности последующего повторного использования. Данные будут считаться устаревшими
по истечении одного часа после обновления, и буду удалены при повторном вызове метода get_response.  

### filters.py  

В данном модуле описан класс MixinFilter, расширяющий функционал классов, наследующихся от абстрактного класса
BaseManager. MixinFilter содержит описание нескольких статических методов, фильтрации и сортировки вакансий по
соответствующим критериям.  

### excel_manager.py и json_manager.py  

Данные модули содержат соответствующие описания классов-менеджеров ExcelManager и JSONManager, отвечающих за управление
списком вакансий. Оба класса имеют схожий функционал, наследуются от BaseManager и MixinFilter, но работают с файлами
соответствующего расширения. В данной программе отдано предпочтение классу ExcelManager, что позволяет пользователю
работать с файлом, созданным программой вне контекста приложения. Однако класс JSONManager в последствии можно будет
использовать для создания более современного интерфейса приложения. Как и обязывает класс-родитель оба класса-менеджера
описывают методы получения сохраненных данных из файла, очистки файла базы данных и обновления информации о вакансиях.  


### utils.py  

В данном модуле описано несколько вспомогательных функций. Большая часть их связана с обработкой информации о
территориальной принадлежности работодателя. Вызов данных функций в ходе работы программы позволяет получать с сайта
HeadHunter.ru больше вакансий, соответствующих запросу пользователя.  

## Алгоритм программы  

1. Создается объект класса ExcelManager, привязанный к файлу данных vacancies.xlsx, расположенном в папке data в корне
проекта.  
2. На основе пользовательских указаний создается объект класса HHResearch.
3. Предлагается установить удобную пользователю валюту для конвертации сумм зарплат.  
По умолчанию принимается код 'RUB'.
4. Отправляется запрос сайту HeadHunter.ru, полученные данные автоматически преобразуются в список объектов класса
Vacancy, с объектами класса Salary, присвоенных атрибуту __salary. Также установленное значение атрибута
required_currency позволяет рассчитать конвертированную сумму зарплаты, что в последствии поможет упростить сортировку
вакансий по размеру зарплаты.  
5. Полученная информация проверяется на наличие дубликатов в текущей базе данных, куда сохраняются только новые
вакансии.
6. Далее пользователю предлагается выбрать несколько критериев отбора и сортировки данных.
7. По указанным критериям из всего объема, хранящегося в базе данных формируется список вакансий, потенциально
подходящих пользователю.
8. В завершении, выводится краткое описание указанного количества вакансий в консоль.
9. Также выводится информация о расположении файла, хранящего все полученные данные.
